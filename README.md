# nexa-ai-life-os



\# NEXA AI Life OS



Multimodal AI • Agentic AI • ML • Deep Learning • GenAI • Computer Vision



\## Overview

NEXA is an AI-powered digital workspace that understands text, images, screenshots, PDFs, voice, and video. It plans tasks, uses specialist agents and tools, verifies results, and remembers useful context.



\## Tech Stack

\- \*\*Frontend\*\*: React/Next.js + Tailwind

\- \*\*Backend\*\*: FastAPI + Python

\- \*\*Database\*\*: PostgreSQL

\- \*\*ML/DL\*\*: PyTorch, Scikit-learn, Transformers

\- \*\*CV\*\*: OpenCV, OCR

\- \*\*RAG\*\*: Embeddings + FAISS

\- \*\*Agents\*\*: LangGraph
